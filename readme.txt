You have essentially built a mini-ERP (Enterprise Resource Planning) tool inspired by the classic Microsoft Northwind framework. Here is the exact lifecycle of how a user interacts with your system, from logging in to completing an invoice transaction.

Step 1: Security Entryway (The Login Gate)Everything starts at the root URL path (/).User action: A visitor tries to type in your app URL.The Guard: Before loading any private pages, the system runs your security rule (verify_session_cookie).The Outcome:If they are not logged in, they are instantly bounced to login.html with a message saying "Please login first".If they provide their credentials, your FastAPI script fetches their username from the users table, securely verifies the plain text password against the encrypted password_hash column using Bcrypt, drops a session tracking cookie into their browser, and grants them entry.

Step 2: The Command Center (The Dashboard)Once authenticated, the user is forwarded to /dashboard (dashboard.html).Database Aggregation: Behind the scenes, the Python code runs rapid aggregate counts across your tables (SELECT COUNT(*)).Visual Presentation: The user sees high-level status layout metric cards:How many background pipeline tasks are currently waiting for 3rd-party engines.A categorized counter breakdown of how many clients vs. agencies exist.Centralized button anchors to navigate to your management modules.
